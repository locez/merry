# TUI MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `merry` with no subcommand open the first full-screen interactive TUI for current-directory coding sessions.

**Architecture:** The TUI lives inside `merry-cli` as a narrow product shell over the existing coding runtime. `merry-runtime` keeps owning sessions, queues, tools, artifacts, permissions, and execution; the TUI owns terminal setup, input/editing state, event projection, rendering, and dispatching existing interactive runtime commands.

**Tech Stack:** Rust 2024, `merry-cli`, `merry-runtime::Runtime::start_interactive_agent_run`, Tokio current-thread runtime, Ratatui `0.30`, Crossterm `0.29` with `event-stream`, existing XDG TOML config.

---

## Scope

Build the first usable vertical slice:

- `merry` with no subcommand opens TUI.
- `merry run`, `merry cmd`, and `merry debug` keep existing behavior.
- TUI starts a new current-directory coding session.
- Bottom input can submit `next` and `backlog`.
- Queue preview shows pending text for `next`, `suspended`, and `backlog`.
- Runtime events render into status, timeline, and detail-ready display models.
- Patch-like tool output is expanded by default; read/list/search are muted by default.
- Human approval is not implemented.
- Theme colors and key bindings are configurable through semantic config keys.

This plan intentionally implements the first vertical slice of the accepted TUI
design. A follow-up plan should implement the full command panel, temporary
detail viewer, artifact opening, and edit/delete/reorder queue management once
the main terminal loop and runtime event projection are stable.

Do not implement global session browsing, `--continue`, `merry tui`, persistent
permission grants, a full file explorer, or a broad terminal golden snapshot
suite.

```rust
use crate::cli_error::{CliError, debug_openai_usage_error, unexpected};
use crate::coding_runtime::{
    HeadlessCodingRuntimeInput, action_process_runner, build_headless_coding_runtime,
    coding_agent_loop_config, coding_loop_smoke_admission_from_current_process,
};
use crate::config::MerryConfig;
use crate::provider_config::{
    RuntimePrimaryProviderConfig, RuntimeProviderBundle, openai_provider_bundle,
    openai_provider_config_bundle,
};
use crate::runtime_config::{
    action_process_backend_options, automatic_compaction_config, subagents_config,
};
use crate::sandbox::ChildHandoff as SandboxChildHandoff;
use merry_runtime::{AgentLoopControl, AgentLoopInput, InteractiveRunEventStream, StepContext};
use std::{env, path::PathBuf};
use tokio_util::sync::CancellationToken;

pub(crate) struct TuiRuntimeSession {
    pub(crate) workspace_root: PathBuf,
    pub(crate) model_label: String,
    pub(crate) stream: InteractiveRunEventStream,
    pub(crate) input: AgentLoopInput,
    pub(crate) control: AgentLoopControl,
}

pub(crate) async fn start_tui_runtime_session(
    sandbox_child_handoff: Option<SandboxChildHandoff>,
    merry_config: Option<&MerryConfig>,
) -> Result<TuiRuntimeSession, CliError> {
    let Some(admission) =
        coding_loop_smoke_admission_from_current_process(sandbox_child_handoff).await
    else {
        return Err(CliError::DebugUsage(
            "merry must run via `merry --with-sandbox`".to_owned(),
        ));
    };

    let config = openai_provider_config_bundle(None, merry_config, debug_openai_usage_error)?;
    let RuntimeProviderBundle {
        primary,
        context_compaction,
        approval_review,
        retry_policy,
    } = openai_provider_bundle(config, unexpected)?;
    let RuntimePrimaryProviderConfig { provider, model } = primary;
    let model_label = model.as_str().to_owned();
    let workspace_root = env::current_dir().map_err(unexpected)?;
    let backend = action_process_runner(
        &workspace_root,
        action_process_backend_options(merry_config).map_err(unexpected)?,
    )?;
    let session_id = default_tui_session_id();
    let runtime = build_headless_coding_runtime(HeadlessCodingRuntimeInput {
        session_id: session_id.as_str(),
        root: &workspace_root,
        admission,
        provider,
        model,
        runner: backend.runner(),
        permissioned_process_runner_factory: backend.permissioned_factory(),
        allow_hidden_workspace_paths: false,
        automatic_compaction: automatic_compaction_config(merry_config).map_err(unexpected)?,
        retry_policy,
        context_compaction,
        approval_review,
        skill_roots: merry_config
            .map(MerryConfig::skill_roots)
            .transpose()
            .map_err(unexpected)?
            .unwrap_or_default(),
        subagents: subagents_config(merry_config).map_err(unexpected)?.into(),
    })?;
    let loop_config = coding_agent_loop_config()?;
    let interactive = runtime
        .start_interactive_agent_run(StepContext::new(CancellationToken::new()), loop_config)
        .map_err(unexpected)?;
    let (stream, input, control) = interactive.split();

    Ok(TuiRuntimeSession {
        workspace_root,
        model_label,
        stream,
        input,
        control,
    })
}

pub(crate) fn default_tui_session_id() -> merry_core::SessionId {
    crate::session_id::new_ephemeral_session_id()
}
```

```rust
    }

    pub(crate) fn insert_char(&mut self, value: char) {
        self.text.insert(self.cursor, value);
        self.cursor += value.len_utf8();
    }

    pub(crate) fn backspace(&mut self) {
        if self.cursor == 0 {
            return;
        }
        let previous = self.text[..self.cursor]
            .char_indices()
            .last()
            .map(|(index, _)| index)
            .unwrap_or(0);
        self.text.drain(previous..self.cursor);
        self.cursor = previous;
    }

    pub(crate) fn clear(&mut self) {
        self.text.clear();
        self.cursor = 0;
    }

    pub(crate) fn take_trimmed(&mut self) -> Option<String> {
        let trimmed = self.text.trim();
        if trimmed.is_empty() {
            return None;
        }
        let value = trimmed.to_owned();
        self.clear();
        Some(value)
    }
}
```

```rust
use super::state::{QueuePreview, TimelineItem, TuiState};
use merry_core::{RuntimeEvent, ToolCallResultStatus, ToolOutput};

#[derive(Debug, Default)]
pub(crate) struct TuiProjector;

impl TuiProjector {
    pub(crate) fn apply(&mut self, event: RuntimeEvent, state: &mut TuiState) {
        match event {
            RuntimeEvent::AssistantMessage { text, .. } => {
                state.timeline_mut().push(TimelineItem::Assistant { text });
            }
            RuntimeEvent::InteractiveRunStateChanged { state: run_state } => {
                state.set_run_state(run_state);
            }
            RuntimeEvent::QueuedInputsChanged { inputs } => {
                state.update_queue_preview(QueuePreview {
                    next: inputs.next,
                    suspended: inputs.suspended,
                    backlog: inputs.backlog,
                });
            }
            RuntimeEvent::UsageUpdated { usage, .. } => {
                state.set_usage(usage);
            }
            RuntimeEvent::ToolCallStarted { call, .. } => {
                state.timeline_mut().push(TimelineItem::Muted {
                    title: format!("tool {}", call.name().as_str()),
                    detail: format!("call {}", call.id().as_str()),
                });
            }
            RuntimeEvent::ToolCallFinished { result, output, .. } => {
                let text = tool_output_text(output);
                if result.status() == ToolCallResultStatus::Failed {
                    let body = result
                        .diagnostic()
                        .map(|diagnostic| {
                            format!("{}: {}\n{}", diagnostic.code(), diagnostic.message(), text)
                        })
                        .unwrap_or(text);
                    state.timeline_mut().push(TimelineItem::Diagnostic {
                        title: "tool failed".to_owned(),
                        body,
                    });
                } else if looks_like_patch(&text) {
                    state.timeline_mut().push(TimelineItem::Expanded {
                        title: "patch".to_owned(),
                        body: text,
                    });
                } else {
                    state.timeline_mut().push(TimelineItem::Muted {
                        title: "tool result".to_owned(),
                        detail: summarize(&text, 96),
                    });
                }
            }
            RuntimeEvent::SubagentCompleted {
                summary,
                output_paths,
                changed_paths,
                ..
            } => {
                state.timeline_mut().push(TimelineItem::Expanded {
                    title: "subagent completed".to_owned(),
                    body: format!(
                        "{summary}\nchanged: {}\noutputs: {}",
                        changed_paths.join(", "),
                        output_paths.join(", ")
                    ),
                });
            }
            RuntimeEvent::SubagentFailed { diagnostic, .. }
            | RuntimeEvent::SubagentCancelled { diagnostic, .. }
            | RuntimeEvent::RunFailed { diagnostic, .. }
            | RuntimeEvent::RunCancelled { diagnostic, .. } => {
                state.timeline_mut().push(TimelineItem::Diagnostic {
                    title: diagnostic.code().to_owned(),
                    body: diagnostic.message().to_owned(),
                });
            }
            RuntimeEvent::Closed => {
                state.timeline_mut().push(TimelineItem::Muted {
                    title: "closed".to_owned(),
                    detail: "runtime stream closed".to_owned(),
                });
            }
            _ => {}
        }
    }
}

fn tool_output_text(output: Option<ToolOutput>) -> String {
    match output {
        Some(ToolOutput::Text { text }) => text,
        Some(ToolOutput::Json { json }) => json,
        None => String::new(),
    }
}

fn looks_like_patch(text: &str) -> bool {
    text.contains("\n+++") || text.contains("\n---") || text.contains("*** Begin Patch")
}

fn summarize(text: &str, max_chars: usize) -> String {
    let compact = text.split_whitespace().collect::<Vec<_>>().join(" ");
    if compact.chars().count() <= max_chars {
        return compact;
    }
    compact.chars().take(max_chars.saturating_sub(3)).collect::<String>() + "..."
}
```

```rust
use ratatui::{
    Frame,
    backend::TestBackend,
    layout::{Constraint, Direction, Layout},
    text::{Line, Span},
    widgets::{Block, Borders, Paragraph, Wrap},
};

pub(crate) fn render(frame: &mut Frame<'_>, state: &TuiState) {
    let root = Layout::default()
        .direction(Direction::Vertical)
        .constraints([
            Constraint::Length(1),
            Constraint::Min(3),
            Constraint::Length(queue_height(state)),
            Constraint::Length(3),
        ])
        .split(frame.area());

    frame.render_widget(Paragraph::new(state.status_text()), root[0]);
    frame.render_widget(
        Paragraph::new(timeline_lines(state)).wrap(Wrap { trim: false }),
        root[1],
    );
    frame.render_widget(
        Paragraph::new(queue_lines(state)).block(Block::default().borders(Borders::TOP)),
        root[2],
    );
    frame.render_widget(
        Paragraph::new(state.input_text()).block(Block::default().borders(Borders::TOP).title("input")),
        root[3],
    );
}

pub(crate) fn render_to_text(state: &TuiState, width: u16, height: u16) -> String {
    let backend = TestBackend::new(width, height);
    let mut terminal = ratatui::Terminal::new(backend).expect("test terminal should build");
    terminal
        .draw(|frame| render(frame, state))
        .expect("test render should draw");
    let buffer = terminal.backend().buffer();
    let area = buffer.area;
    let mut text = String::new();
    for y in area.y..area.y + area.height {
        for x in area.x..area.x + area.width {
            text.push_str(buffer[(x, y)].symbol());
        }
        text.push('\n');
    }
    text
}

fn timeline_lines(state: &TuiState) -> Vec<Line<'static>> {
    state
        .timeline()
        .iter()
        .flat_map(|item| match item {
            TimelineItem::Assistant { text } => vec![Line::from(text.clone())],
            TimelineItem::Muted { title, detail } => {
                vec![Line::from(vec![Span::raw(title.clone()), Span::raw(": "), Span::raw(detail.clone())])]
            }
            TimelineItem::Expanded { title, body } | TimelineItem::Diagnostic { title, body } => {
                let mut lines = vec![Line::from(title.clone())];
                lines.extend(body.lines().map(|line| Line::from(line.to_owned())));
                lines
            }
        })
        .collect()
}

fn queue_lines(state: &TuiState) -> Vec<Line<'static>> {
    let queue = state.queue_preview();
    let mut lines = Vec::new();
    if !queue.next.is_empty() {
        lines.push(Line::from("Next"));
        lines.extend(
            queue
                .next
                .iter()
                .enumerate()
                .map(|(index, item)| Line::from(format!("  {}. {}", index + 1, item.display_text(72)))),
        );
    }
    if !queue.suspended.is_empty() {
        lines.push(Line::from("Suspended"));
        lines.extend(
            queue
                .suspended
                .iter()
                .enumerate()
                .map(|(index, item)| Line::from(format!("  {}. {}", index + 1, item.display_text(72)))),
        );
    }
    if !queue.backlog.is_empty() {
        lines.push(Line::from("Backlog"));
        lines.extend(
            queue
                .backlog
                .iter()
                .enumerate()
                .map(|(index, item)| Line::from(format!("  {}. {}", index + 1, item.display_text(72)))),
        );
    }
    lines
}

fn queue_height(state: &TuiState) -> u16 {
    let queue = state.queue_preview();
    let count = queue.next.len() + queue.suspended.len() + queue.backlog.len();
    if count == 0 {
        1
    } else {
        (count + 4).min(8) as u16
    }
}
```

```rust
use super::keymap::KeyAction;
use super::projector::TuiProjector;
use super::render;
use super::runtime::TuiRuntimeSession;
use super::state::TuiState;
use super::terminal::{TerminalEvent, TerminalSession};
use crate::cli_error::{CliError, unexpected};
use futures_util::StreamExt;
use merry_runtime::InterruptReason;
use std::time::Duration;
use tokio::time;

#[derive(Debug, Clone, PartialEq, Eq)]
pub(crate) enum ControllerEffect {
    None,
    SubmitNext(String),
    SubmitBacklog(String),
    Interrupt,
    Quit,
}

pub(crate) fn handle_key_action(action: KeyAction, state: &mut TuiState) -> ControllerEffect {
    match action {
        KeyAction::SubmitNext => state
            .input_mut()
            .take_trimmed()
            .map(ControllerEffect::SubmitNext)
            .unwrap_or(ControllerEffect::None),
        KeyAction::SubmitBacklog => state
            .input_mut()
            .take_trimmed()
            .map(ControllerEffect::SubmitBacklog)
            .unwrap_or(ControllerEffect::None),
        KeyAction::Interrupt => ControllerEffect::Interrupt,
        KeyAction::Quit => ControllerEffect::Quit,
        _ => ControllerEffect::None,
    }
}

pub(crate) async fn run_controller(
    mut terminal: TerminalSession,
    mut session: TuiRuntimeSession,
    mut state: TuiState,
) -> Result<(), CliError> {
    let mut projector = TuiProjector::default();
    let mut redraw = time::interval(Duration::from_millis(33));
    render_once(&mut terminal, &state)?;

    loop {
        tokio::select! {
            _ = redraw.tick() => {
                render_once(&mut terminal, &state)?;
            }
            maybe_event = terminal.next_event() => {
                match maybe_event.map_err(unexpected)? {
                    Some(TerminalEvent::Key(key)) => {
                        if let Some(action) = state.keymap().action_for(key.into()) {
                            match handle_key_action(action, &mut state) {
                                ControllerEffect::None => {}
                                ControllerEffect::SubmitNext(text) => {
                                    session.input.submit_next(&text).await.map_err(unexpected)?;
                                }
                                ControllerEffect::SubmitBacklog(text) => {
                                    session.input.enqueue(&text).await.map_err(unexpected)?;
                                }
                                ControllerEffect::Interrupt => {
                                    session.control.interrupt(InterruptReason::User).await.map_err(unexpected)?;
                                }
                                ControllerEffect::Quit => {
                                    session.control.close().await.map_err(unexpected)?;
                                    break;
                                }
                            }
                        } else {
                            state.input_mut().handle_key(key);
                        }
                    }
                    Some(TerminalEvent::Resize) => {
                        render_once(&mut terminal, &state)?;
                    }
                    None => break,
                }
            }
            maybe_runtime_event = session.stream.next() => {
                match maybe_runtime_event {
                    Some(event) => projector.apply(event, &mut state),
                    None => break,
                }
            }
        }
    }

    Ok(())
}

fn render_once(terminal: &mut TerminalSession, state: &TuiState) -> Result<(), CliError> {
    terminal.draw(|frame| render::render(frame, state)).map_err(unexpected)?;
    Ok(())
}
```

```rust
use crossterm::{
    cursor,
    event::{DisableBracketedPaste, EnableBracketedPaste, Event, EventStream, KeyEvent},
    execute,
    terminal::{
        EnterAlternateScreen, LeaveAlternateScreen, disable_raw_mode, enable_raw_mode,
    },
};
use futures_util::StreamExt;
use ratatui::{Frame, Terminal, backend::CrosstermBackend};
use std::io::{self, Stdout};

pub(crate) enum TerminalEvent {
    Key(KeyEvent),
    Resize,
}

pub(crate) struct TerminalSession {
    terminal: Terminal<CrosstermBackend<Stdout>>,
    events: EventStream,
}

impl TerminalSession {
    pub(crate) fn enter() -> io::Result<Self> {
        enable_raw_mode()?;
        let mut stdout = io::stdout();
        execute!(
            stdout,
            EnterAlternateScreen,
            EnableBracketedPaste,
            cursor::Hide
        )?;
        let backend = CrosstermBackend::new(stdout);
        let terminal = Terminal::new(backend)?;
        Ok(Self {
            terminal,
            events: EventStream::new(),
        })
    }

    pub(crate) async fn next_event(&mut self) -> io::Result<Option<TerminalEvent>> {
        while let Some(event) = self.events.next().await {
            match event? {
                Event::Key(key) => return Ok(Some(TerminalEvent::Key(key))),
                Event::Resize(_, _) => return Ok(Some(TerminalEvent::Resize)),
                _ => {}
            }
        }
        Ok(None)
    }

    pub(crate) fn draw(
        &mut self,
        draw: impl FnOnce(&mut Frame<'_>),
    ) -> io::Result<()> {
        self.terminal.draw(draw).map(|_| ())
    }
}

impl Drop for TerminalSession {
    fn drop(&mut self) {
        let _ = disable_raw_mode();
        let _ = execute!(
            self.terminal.backend_mut(),
            cursor::Show,
            DisableBracketedPaste,
            LeaveAlternateScreen
        );
    }
}
```

```rust
impl TuiTheme {
    pub(crate) fn from_config(config: &crate::config::TuiThemeToml) -> Result<Self, crate::config::ConfigError> {
        let mut theme = Self::default();
        for (slot, value) in [
            (SemanticColor::Status, config.status.as_deref()),
            (SemanticColor::Muted, config.muted.as_deref()),
            (SemanticColor::Focus, config.focus.as_deref()),
            (SemanticColor::Selection, config.selection.as_deref()),
            (SemanticColor::DiffAdd, config.diff_add.as_deref()),
            (SemanticColor::DiffDelete, config.diff_delete.as_deref()),
            (SemanticColor::Warning, config.warning.as_deref()),
            (SemanticColor::Error, config.error.as_deref()),
            (SemanticColor::Risk, config.risk.as_deref()),
            (SemanticColor::Success, config.success.as_deref()),
        ] {
            if let Some(value) = value {
                theme.set_color(slot, parse_color(value)?);
            }
        }
        Ok(theme)
    }

    fn set_color(&mut self, slot: SemanticColor, color: Color) {
        if let Some((_, existing)) = self.colors.iter_mut().find(|(candidate, _)| *candidate == slot) {
            *existing = color;
        }
    }
}

fn parse_color(value: &str) -> Result<Color, crate::config::ConfigError> {
    match value {
        "black" => Ok(Color::Black),
        "red" => Ok(Color::Red),
        "green" => Ok(Color::Green),
        "yellow" => Ok(Color::Yellow),
        "blue" => Ok(Color::Blue),
        "magenta" => Ok(Color::Magenta),
        "cyan" => Ok(Color::Cyan),
        "gray" => Ok(Color::Gray),
        "dark_gray" => Ok(Color::DarkGray),
        "white" => Ok(Color::White),
        other => Err(crate::config::ConfigError::Invalid(format!(
            "unsupported TUI color {other:?}"
        ))),
    }
}
```

```rust
impl Keymap {
    pub(crate) fn from_config(config: &crate::config::TuiKeymapToml) -> Result<Self, crate::config::ConfigError> {
        let mut keymap = Self::default();
        for (action, binding) in [
            (KeyAction::SubmitNext, config.submit_next.as_deref()),
            (KeyAction::SubmitBacklog, config.submit_backlog.as_deref()),
            (KeyAction::Interrupt, config.interrupt.as_deref()),
            (KeyAction::Quit, config.quit.as_deref()),
        ] {
            if let Some(binding) = binding {
                keymap.set_binding(action, parse_binding(binding)?);
            }
        }
        Ok(keymap)
    }

    fn set_binding(&mut self, action: KeyAction, binding: KeyBinding) {
        self.bindings.retain(|(_, existing)| *existing != action);
        self.bindings.push((binding, action));
    }
}

fn parse_binding(value: &str) -> Result<KeyBinding, crate::config::ConfigError> {
    match value {
        "enter" => Ok(KeyBinding::new(KeyCode::Enter, KeyModifiers::NONE)),
        "esc" => Ok(KeyBinding::new(KeyCode::Esc, KeyModifiers::NONE)),
        "ctrl+b" => Ok(KeyBinding::new(KeyCode::Char('b'), KeyModifiers::CONTROL)),
        "ctrl+c" => Ok(KeyBinding::new(KeyCode::Char('c'), KeyModifiers::CONTROL)),
        "ctrl+q" => Ok(KeyBinding::new(KeyCode::Char('q'), KeyModifiers::CONTROL)),
        other => Err(crate::config::ConfigError::Invalid(format!(
            "unsupported TUI key binding {other:?}"
        ))),
    }
}
```

## Self-Review

- Spec coverage:
  - Default `merry` TUI route: Task 1 and Task 7.
  - No `merry tui`, no `--continue`: Task 1 tests and scope.
  - Current-directory new session: Task 2.
  - Ratatui + Crossterm, no adapter: Tasks 1, 5, 6.
  - `next`/`backlog`/`suspended` previews with real text: Tasks 3, 4, 5, 6.
  - Runtime event display defaults: Task 4 and Task 5.
  - No human approval source: scope and projector display only.
  - Configurable colors/keybindings: Task 8.
  - Limited tests focused on stable contracts: Tasks 1, 3, 4, 5, 6, 8, 9.
- Follow-up coverage deliberately left out of this MVP plan:
  - Full command panel.
  - Temporary detail viewer and artifact opening.
  - Queue edit/delete/reorder controls.
  - Rich per-tool renderers beyond first-pass muted/expanded display classes.
- Scope guard:
  - This plan does not add session browsing, persistent permission grants, a file explorer, or broad snapshot tests.
  - This plan keeps runtime execution and queue semantics in `merry-runtime`.
- Known implementation risks:
  - The exact Ratatui `Buffer` cell access API may need minor adjustment against `0.30`; keep that adjustment inside `render.rs` tests.
  - The first manual smoke requires a real terminal and valid existing provider config.
  - If `merry --with-sandbox` cannot run inside the current host sandbox, record that as an environment limitation and run the smoke from a normal terminal.
